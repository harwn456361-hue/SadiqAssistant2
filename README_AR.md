# صديقي الصوتي — نسخة أولية

هذه بداية تعليمية لمشروع أندرويد. توفر:
- واجهة عربية للكتابة.
- إدخال صوتي عبر خدمة التعرف على الكلام في أندرويد (قد يحتاج الإنترنت حسب محرك الجهاز).
- قراءة الرد بصوت الجهاز.
- حفظ آخر 300 رسالة محلياً على الجهاز.
- ردود تجريبية بسيطة تعمل دون اتصال.

## مهم
هذه ليست بعدُ مساعد ذكاء اصطناعي حقيقياً، ولا تنفذ بحثاً على الإنترنت. الردود حالياً تجريبية. اختيار صوت رجل/امرأة يعتمد على الأصوات العربية التي يوفرها محرك TTS على الجهاز؛ أندرويد لا يضمن توفر الجنسين أو تمييزهما.

## بناء التطبيق
يتطلب بناء APK عادةً كمبيوتراً عليه Android Studio أو بيئة بناء سحابية متوافقة:
1. افتح المشروع في Android Studio.
2. انتظر مزامنة Gradle.
3. شغّل التطبيق على جهاز أندرويد أو اختر Build > Build APK(s).
4. لا تنشر مفتاح API داخل التطبيق عند إضافة الذكاء الاصطناعي؛ استخدم خادماً وسيطاً آمناً.

## الخطوة التالية
إضافة خدمة ذكاء اصطناعي مجانية/منخفضة التكلفة عبر الإنترنت، مع إعدادات للمستخدم ومصادر بحث. افحص حدود الخدمة وتكلفتها قبل الربط ولا تفترض أن API مجاني.
